# WEB Beyblade Community

## Feature
1. Home page, berisi informasi terkait komunitas, Foto event, dan informasi umum lainya
2. Event, berisi upcomming event, event yang sedang berjalan, formulir pendaftaran event
3. Leader Board, berisi leaderboard member
4. Membersip, informasi pendaftaran dan benerit
5. Login Dengan Google
6. Profile Member berisi
    - Foto
    - latest deck
    - top most blade
    - Achivement
7. Semua data menggunakan google spreadsheet untuk proses penyimpanan
8. web akan dihosting di github.io agar gratis
9. Halaman Pengelolaan yang terhubung ke spreasheet
    - Pengelolaan Home Page
    - Pengelolaan Event
    - Input Point Leaderboard dari hasil event/tournament
    - Pendaftaran member baru
10. untuk member/player yang menang dalam event otomatis tarcatat achiementnya ke data profilenya

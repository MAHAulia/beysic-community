# Entities — UI Re-skin

Re-skin ini **tidak memperkenalkan, mengubah, atau menghapus entity data apa pun**. Model data situs (Member, Event, EventResult, Achievement, dll.) tetap persis seperti sebelumnya, dimiliki backend Apps Script + Google Spreadsheet, dan di luar ruang lingkup intent ini.

```yaml
entities: []
note: >-
  UI-only re-skin. Tidak ada entity baru atau perubahan skema. Entity domain
  yang ada tetap dikelola oleh apps-script/ (Apps Script + Spreadsheet) dan
  dibekukan untuk intent ini.
```

## Ringkasan
Tidak ada perubahan entity. Lihat `aidlc/spaces/default/codekb/web/business-overview.md` dan dokumen domain-design intent sebelumnya (`261019-beyblade-community-web`) untuk model data yang berlaku. Perubahan intent ini murni lapisan presentasi (design token, CSS modular, markup presentasional).

# Stakeholder Map — Website Komunitas Beyblade

> Fase: Ideation · Stage: Intent Capture & Framing

## Key Stakeholders & Interests

| Stakeholder | Kepentingan Utama | Source |
|---|---|---|
| Admin / Pengurus komunitas | Mengelola konten home page, event, input poin leaderboard, dan pendaftaran member baru | [Q5] |
| Member / Pemain | Profil pribadi (foto, latest deck, top blade, achievement) dan posisi di leaderboard | [Q5] |
| Pengunjung / Calon member | Informasi komunitas dan cara bergabung (membership) | [Q5] |
| Penyelenggara event / Wasit tournament | Hasil pertandingan sebagai sumber poin leaderboard dan achievement | [Q5] |

## Decision-makers vs. Influencers

| Peran | Tipe | Catatan | Source |
|---|---|---|---|
| Pemilik / Pengurus utama | Decision-maker | Memutuskan scope dan prioritas fitur versi pertama | [Q6] |
| Pengurus/admin komunitas | Influencer | Memberi masukan konten dan jalannya event | [Q5] |
| Member/pemain | Influencer | Pengguna akhir fitur profil & leaderboard | [Q5] |

## Communication Requirements

| Kebutuhan Komunikasi | Deskripsi | Source |
